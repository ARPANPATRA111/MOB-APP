# Product Requirements

## Product Intent

MOB helps small vendors replace notebooks and manual stock tracking with an offline mobile POS. The minimum useful workflow is:

```text
add product -> search or scan product -> create bill -> stock decreases -> receipt opens -> report updates
```

## Target Users

- Small shopkeepers.
- Local vendors.
- Kiosk operators.
- Sellers with unreliable internet access.

## Core Requirements

- Work offline.
- Add and edit products.
- Search products by name or barcode.
- Scan or manually enter barcode.
- Create sale from a cart.
- Deduct stock after sale.
- Persist sale history.
- Show receipt from saved sale.
- Show basic reports from persisted data.
- Preserve legacy data during migration.

## Out Of Scope For Current Phase

- Cloud sync.
- Multi-user roles.
- Payment gateway.
- Production UI redesign.
- Advanced GST/accounting workflows.
- Web dashboard.
